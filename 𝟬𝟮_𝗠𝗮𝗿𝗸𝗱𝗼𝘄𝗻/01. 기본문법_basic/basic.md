## 마크다운 기본 문법 ✨

# 01 마크다운이란?
→ **마크다운(Markdown)**은 일반 텍스트에 기호를 사용해서 문서를 꾸미는 문법

마크다운 파일의 확장자는 `.md` = 그래서 파일 이렇게 만들 때 뒤에 `.md`를 붙임

# 02 제목 작성
`#` 기호를 사용해서 제목을 작성함

```markdown
# 제목 1
## 제목 2
### 제목 3
#### 제목 4
##### 제목 5
###### 제목 6
```

`#`의 개수가 많아질수록 제목의 크기가 작아짐

→ `#` 뒤에는 한 칸 띄어쓰기 필요


# 03 줄바꿈
문장 끝에 띄어쓰기 2번을 입력하면 줄바꿈 가능

```markdown
첫 번째 줄  
두 번째 줄
```

또는 `<br>` 태그를 사용할 수도 있음

```html
첫 번째 줄<br>
두 번째 줄
```

이 외에도 깃허브에 쓸 땐 엔터 2번, `\`로 줄바꿈 가능 !!

# 04 문단 나누기
문단을 나누려면 한 줄을 비워두면 됨

```markdown
첫 번째 문단

두 번째 문단
```

# 05 글자 굵게 표시
글자 앞뒤에 `**`를 붙이면 굵게 표시됨

```markdown
**굵게 표시할 내용**
```

**굵게 표시할 내용**

# 06 글자 기울이기
글자 앞뒤에 `*`를 붙이면 기울임 표시됨

```markdown
*기울일 내용*
```

*기울일 내용*

# 07 굵게 + 기울이기
글자 앞뒤에 `***`를 붙이면 굵게 기울임 표시됨

```markdown
***굵게 기울일 내용***
```

***굵게 기울일 내용***

# 08 취소선
글자 앞뒤에 `~~`를 붙이면 취소선 표시됨

```markdown
~~취소할 내용~~
```

~~취소할 내용~~

# 09 밑줄
마크다운에는 기본 밑줄 문법이 없어서 HTML 태그를 사용함

```html
<u>밑줄 표시할 내용</u>
```

<u>밑줄 표시할 내용</u> 아니근데아까해보니까인용문에선안되는것같앗음....ㅠㅠ

# 10 형광펜 표시
`<mark>` 태그를 사용하면 형광펜 효과를 적용할 수 있음

```html
<mark>강조할 내용</mark>
```

<mark>강조할 내용</mark>

# 11 인용문
`>` 기호를 사용해서 인용문을 작성할 수 있음

```markdown
> 인용문 작성
```

> 인용문 작성

# 12 순서 없는 목록
`-`, `*`, `+` 기호를 사용해서 목록을 작성할 수 있음

```markdown
- 첫 번째 항목
- 두 번째 항목
- 세 번째 항목
```

- 첫 번째 항목
- 두 번째 항목
- 세 번째 항목

## 들여쓰기 목록
목록 앞에 공백을 추가하면 하위 목록을 만들 수 있음

```markdown
- Git
  - commit
  - push
  - pull
```

- Git
  - commit
  - push
  - pull

# 13 순서 있는 목록
숫자와 `.`을 사용해서 순서가 있는 목록을 작성할 수 있음

```markdown
1. 첫 번째 항목
2. 두 번째 항목
3. 세 번째 항목
```

1. 첫 번째 항목
2. 두 번째 항목
3. 세 번째 항목

# 14 체크박스
`- [ ]`를 사용하면 체크하지 않은 체크박스를 만들 수 있음

`- [x]`를 사용하면 체크된 체크박스를 만들 수 있음

```markdown
- [ ] 할 일
- [x] 완료한 일
```

- [ ] 할 일
- [x] 완료한 일

# 15 인라인 코드
코드나 명령어 앞뒤에 백틱 `` ` ``을 사용함

```markdown
`git status`
```

`git status`

# 16 코드 블록
여러 줄의 코드를 작성할 때는 백틱 3개를 사용함

````markdown
```bash
git add .
git commit -m "수정 내용"
git push origin main
```
````

언어를 지정하면 코드에 색상이 적용됨

# 17 링크
대괄호 안에 링크 이름을 작성하고, 소괄호 안에 주소를 작성함

```markdown
[우울해우우ㅜㄹ해](https://sad.com)
```

[우울해우우ㅜㄹ해](https://sad.com) → 클릭하면 사이트로 이동됨

# 18 이미지
이미지를 추가할 때는 다음 형식을 사용함

```markdown
![이미지 설명](이미지 주소)
```

로컬에 있는 이미지를 연결할 수도 있음

```markdown
![어쩌구저쩌구](./images/TT.png)
```

# 20 표 만들기
`|`와 `-`를 사용해서 표를 만들 수 있음

```markdown
| 명령어 | 설명 |
| --- | --- |
| `git add` | 파일 추가 |
| `git commit` | 변경 사항 저장 |
| `git push` | GitHub에 업로드 |
```

| 명령어 | 설명 |
| --- | --- |
| `git add` | 파일 추가 |
| `git commit` | 변경 사항 저장 |
| `git push` | GitHub에 업로드 |

# 21 HTML 태그 사용
마크다운에서 HTML 태그를 사용할 수 있음

```html
<u>밑줄</u>
<mark>형광펜</mark>
<br>
```

| 태그 | 설명 |
| --- | --- |
| `<u>` | 밑줄 |
| `<mark>` | 형광펜 |
| `<br>` | 줄바꿈 |
| `<hr>` | 수평선 |

형광펜이랑 밑줄 말곤 굳이긴함 더 편한게 잇으니 그걸 쓰는게 아직까진 더 조은 것 같음 !!

# 22 접었다 펼치기
`<details>`와 `<summary>` 태그를 사용함

```html
<details>
<summary>클릭해서 내용 확인</summary>

숨겨진 내용

</details>
```

펼친 상태로 두려면 `<details open>`이라고 첫번째 줄을 바꾸면 됨

# 23 특수문자 표시
마크다운 문법으로 사용되는 기호를 그대로 표시하려면 앞에 `\`를 붙임

```markdown
\# 제목이 아님
\* 별표가 아님
```

# 24 마크다운 기본 문법 정리 ⭐⭐⭐

| 문법 | 설명 |
| --- | --- |
| `# 제목` | 제목 |
| `**내용**` | 굵게 |
| `*내용*` | 기울임 |
| `~~내용~~` | 취소선 |
| `<u>내용</u>` | 밑줄 |
| `<mark>내용</mark>` | 형광펜 |
| `> 내용` | 인용문 |
| `- 내용` | 순서 없는 목록 |
| `1. 내용` | 순서 있는 목록 |
| `` `코드` `` | 인라인 코드 |
| `[이름](주소)` | 링크 |
| `![설명](주소)` | 이미지 |
| `---` | 수평선 |
| `\| 내용 \|` | 표 |
