## 강조문법
<sub><sub>사실강조문법이긴한데위에쓴게똑같이나와서음........깃헙은css가안돼서머거기서거기임비슷함

# 01 굵게 표시
글자 앞뒤에 `**`를 붙이면 굵게 표시됨

```markdown
**굵게 표시할 내용**
```

**굵게 표시할 내용**

또는 `__`를 사용할 수도 있음

```markdown
__굵게 표시할 내용__
```

# 02 기울임 표시
글자 앞뒤에 `*`를 붙이면 기울임 표시됨

```markdown
*기울일 내용*
```

*기울일 내용*

또는 `_`를 사용할 수도 있음

```markdown
_기울일 내용_
```

# 03 굵게 + 기울임 표시
글자 앞뒤에 `***`를 붙이면 굵게 기울임 표시됨

```markdown
***굵게 기울일 내용***
```

***굵게 기울일 내용***

또는 `___`를 사용할 수도 있음

```markdown
___굵게 기울일 내용___
```

# 04 취소선
글자 앞뒤에 `~~`를 붙이면 취소선 표시됨

```markdown
~~취소할 내용~~
```

~~취소할 내용~~

# 05 밑줄
마크다운에는 기본 밑줄 문법이 없어서 HTML 태그를 사용함

```html
<u>밑줄 표시할 내용</u>
```

<u>밑줄 표시할 내용</u>

# 06 형광펜 표시
`<mark>` 태그를 사용하면 형광펜 효과를 적용할 수 있음

```html
<mark>강조할</mark> 내용
```

<mark>강조할</mark> 내용

기본문법복사붙여넣기라뭐할게없다\
이렇게 중간에만 형광 넣는 것도 가능함

# 07 글자 색상 변경
GitHub 마크다운에서는 기본적으로 글자 색상을 직접 변경할 수 없음

색상을 변경하려면 HTML 태그를 사용할 수 있지만 GitHub에서 일부 태그는 제한될 수 있음

```html
<span style="color: red;">빨간색 글자</span>
```

→ GitHub에서는 위와 같은 `style` 속성이 정상적으로 적용되지 않을 수 있음

# 08 여러 강조 문법 함께 사용
여러 강조 문법을 함께 사용할 수 있음

```markdown
***굵게 기울인 내용***
```

```html
<u><mark>밑줄과 형광펜을 함께 적용한 내용</mark></u>
```

<u><mark>밑줄과 형광펜을 함께 적용한 내용</mark></u>

# 09 강조 문법 정리

| 문법 | 설명 |
| --- | --- |
| `**내용**` | 굵게 |
| `__내용__` | 굵게 |
| `*내용*` | 기울임 |
| `_내용_` | 기울임 |
| `***내용***` | 굵게 + 기울임 |
| `___내용___` | 굵게 + 기울임 |
| `~~내용~~` | 취소선 |
| `<u>내용</u>` | 밑줄 |
| `<mark>내용</mark>` | 형광펜 |
