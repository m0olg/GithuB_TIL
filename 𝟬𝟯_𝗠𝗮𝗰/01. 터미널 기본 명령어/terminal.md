## 맥 터미널 기본 명령어

<br>
<br>

# 01 터미널이란?

→ 터미널은 **문자 명령어를 입력해 맥의 파일과 프로그램을 조작하는 앱**임

터미널에서는 다음과 같은 작업을 할 수 있음

* 폴더 및 파일 생성
* 폴더 이동
* 파일 삭제 및 이름 변경
* Git 저장소 관리
* GitHub에 코드 업로드 및 다운로드




# 02 터미널 실행 방법

맥에서 다음 방법으로 터미널을 실행할 수 있음

### ① Spotlight 사용

`Command + Space`를 누른 후 `터미널` 또는 `Terminal`을 검색함

### ② 응용 프로그램에서 실행

`응용 프로그램` → `유틸리티` → `터미널`




# 03 현재 위치 확인하기

```bash
pwd
```

현재 터미널이 위치한 폴더의 경로를 확인하는 명령어

`pwd`는 **Print Working Directory**의 약자임

### 예시

```bash
/Users/username/Desktop
```

현재 바탕화면 폴더에 위치해 있다는 의미임




# 04 파일과 폴더 목록 확인하기

```bash
ls
```

현재 폴더 안에 있는 파일과 폴더 목록을 보여줌

### ① 숨김 파일까지 확인하기

```bash
ls -la
```

* `-l`: 파일의 상세 정보 표시
* `-a`: 숨김 파일까지 표시

Git에서는 `.git`이나 `.gitignore`처럼 `.`으로 시작하는 숨김 파일을 자주 사용하므로 `ls -la`를 알아두는 것이 좋음




# 05 폴더 이동하기

```bash
cd 폴더명
```

특정 폴더로 이동하는 명령어

### 예시

```bash
cd Desktop
```

바탕화면 폴더로 이동함

### ① 한 단계 위 폴더로 이동하기

```bash
cd ..
```

현재 폴더의 상위 폴더로 이동함

### ② 홈 폴더로 이동하기

```bash
cd ~
```

사용자의 홈 디렉터리로 이동함

### ③ 이전에 있던 폴더로 돌아가기

```bash
cd -
```

직전에 위치했던 폴더로 이동함

> 폴더 이름에 띄어쓰기가 포함되어 있으면 큰따옴표를 사용해야 함

```bash
cd "My Project"
```




# 06 폴더 생성하기

```bash
mkdir 폴더명
```

새로운 폴더를 생성하는 명령어

`mkdir`은 **Make Directory**의 약자임

### 예시

```bash
mkdir github-practice
```

`github-practice`라는 폴더가 생성됨




# 07 파일과 폴더 삭제하기

### ① 파일 삭제

```bash
rm 파일명
```

### 예시

```bash
rm test.txt
```

`test.txt` 파일이 삭제됨

### ② 폴더 삭제

```bash
rm -r 폴더명
```

`-r`은 폴더 안의 내용까지 함께 삭제하기 위해 사용함

> `rm`은 휴지통으로 이동하지 않고 바로 삭제하므로 조심해야 함  
> 특히 `rm -rf`는 파일과 폴더를 강제로 삭제하므로 함부로 사용하면 안 됨




# 08 파일 및 폴더 복사하기

### ① 파일 복사

```bash
cp 원본파일 복사할파일
```

### 예시

```bash
cp original.txt copy.txt
```

`original.txt` 파일이 `copy.txt`라는 이름으로 복사됨

### ② 폴더 복사

```bash
cp -R 원본폴더 복사할폴더
```

`-R`은 폴더 내부까지 함께 복사하기 위해 사용함




# 09 파일 및 폴더 이동하기

```bash
mv 기존위치/파일명 이동할위치
```

파일이나 폴더를 다른 위치로 이동하는 명령어

### 예시

```bash
mv test.txt Desktop
```

`test.txt`를 바탕화면으로 이동함

### 파일 이름 변경하기

```bash
mv 기존이름 새이름
```

### 예시

```bash
mv old.txt new.txt
```

`old.txt`의 이름이 `new.txt`로 변경됨




# 10 터미널 화면 정리하기

```bash
clear
```

터미널에 표시된 내용을 지우는 명령어

화면의 내용만 지우며 파일이나 폴더가 삭제되는 것은 아님
