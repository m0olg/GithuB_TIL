# 01 Git의 세 가지 영역

→ Git은 파일을 **작업 디렉터리 → 스테이징 영역 → 저장소** 순서로 거쳐 기록 !!

작업 디렉터리는 내가 실제로 파일을 만들고 고치는 폴더임 \
스테이징 영역은 "이번 커밋에 넣을 파일"을 잠깐 모아두는 대기실 같은 곳이고 저장소는 커밋으로 확정된 기록이 쌓이는 곳임

파일을 고쳤다고 바로 기록되는 것은 아니고, 기록할 파일을 고르는 `add`와 기록을 확정하는 `commit`, 이렇게 두 단계를 거침 \
여러 파일을 고쳤더라도 관련 있는 것끼리만 묶어서 커밋할 수 있도록 단계를 나눠둔 것임


> 작업 디렉터리  →  git add  →  스테이징 영역  →  git commit  →  저장소
