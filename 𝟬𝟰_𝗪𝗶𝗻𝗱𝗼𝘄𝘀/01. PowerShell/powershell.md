## 윈도우 PowerShell 기본 명령어

<br>
<br>

# 01 PowerShell이란?

→ <mark>PowerShell은 **윈도우에 기본으로 들어 있는 터미널 도구**임

맥의 터미널과 같은 역할을 하며 문자 명령어로 폴더와 파일을 다루고 Git 명령어도 입력할 수 있음 \
윈도우 10과 11에는 따로 설치하지 않아도 들어 있어서 바로 쓸 수 있음

> 윈도우에 기본으로 들어 있는 것은 `Windows PowerShell 5.1`이고, 더 새로운 `PowerShell 7`은 따로 설치해야 함 이 TIL의 명령어는 기본 버전에서 모두 동작 !!


<br>
<br>


# 02 PowerShell 실행 방법

윈도우에서는 다음 방법으로 PowerShell을 실행할 수 있음

### ① 시작 메뉴에서 검색

시작 메뉴에서 `PowerShell`을 검색해서 실행함

### ② 단축키 사용

`Win + X`를 누르면 나오는 메뉴에서 `Windows PowerShell` 또는 `터미널`을 선택함

### ③ VS Code 터미널 사용

VS Code 하단의 `터미널` 탭에서 바로 쓸 수 있음 오른쪽에 `powershell`이라고 표시되어 있으면 PowerShell이 열려 있다는 뜻임

### ④ 원하는 폴더에서 바로 열기

탐색기에서 원하는 폴더에 들어간 뒤 위쪽 주소창에 `powershell`을 입력하고 `Enter`를 누르면 그 폴더가 현재 위치인 상태로 PowerShell이 열림

폴더를 찾아 이동하는 과정을 건너뛸 수 있어서 편함


<br>
<br>


# 03 현재 위치 확인과 이동

현재 위치는 `pwd`로 확인함. 맥과 똑같이 입력하면 되고, 윈도우에서는 `C:\Users\사용자이름\Desktop`처럼 드라이브 문자로 시작하는 경로가 출력됨

폴더 이동도 맥과 같은 `cd`를 사용함. `cd Desktop`처럼 폴더 이름을 적으면 그 폴더로 들어가고, `cd ..`는 한 단계 위로 올라감. `cd ~`는 사용자의 홈 폴더로 이동하는 명령어임

```powershell
cd Desktop
cd ..
```

다른 드라이브로 이동할 때는 `D:`처럼 드라이브 문자를 입력하고 `Enter`를 누르거나, `cd D:\폴더` 형태로 경로를 통째로 적으면 됨

폴더 이름에 띄어쓰기가 있으면 `cd "My Project"`처럼 큰따옴표로 감싸야 함

> `cd -`로 직전 위치로 돌아가는 기능은 PowerShell 7부터 지원되며, 기본 버전에서는 동작하지 않음


<br>
<br>


# 04 파일과 폴더 목록 확인하기

`ls`를 입력하면 현재 폴더 안의 파일과 폴더 목록이 나옴 `dir`도 같은 역할을 함

숨김 파일까지 보려면 `ls -Force`를 사용함. 맥에서 쓰던 `ls -la`는 PowerShell에서 동작하지 않으므로 주의해야 함 \
Git에서 쓰는 `.git` 폴더도 숨김 속성이라 `ls`만으로는 보이지 않고, `ls -Force`로 확인할 수 있음


<br>
<br>


# 05 폴더와 파일 만들기

폴더는 맥과 같이 `mkdir 폴더명`으로 만듦

빈 파일을 만드는 `touch`는 PowerShell에 없음 대신 아래처럼 `New-Item`을 사용

```powershell
New-Item test.txt -ItemType File
```

`-ItemType File`은 "파일로 만들어라"라는 뜻임 \
폴더를 만들 때는 `-ItemType Directory`를 쓰는데 이건 `mkdir`이 대신 해주는 것


<br>
<br>


# 06 파일과 폴더 삭제하기

파일은 `rm 파일명`으로 지움 `rm`은 실제로는 `Remove-Item`의 별칭임

폴더를 안의 내용과 함께 지우려면 `-Recurse`를 붙이고, 확인 질문 없이 지우려면 `-Force`도 붙임

```powershell
Remove-Item -Recurse -Force 폴더명
```

맥에서 쓰던 `rm -rf`는 PowerShell에서 에러가 나므로 위처럼 풀어서 써야 함

> 삭제한 파일은 휴지통으로 가지 않고 바로 영구 삭제됨
> 지우기 전에 `ls`로 폴더 안을 한 번 확인하는 것이 좋음

폴더가 "다른 프로세스가 사용 중"이라는 에러로 지워지지 않을 때가 있음

VS Code나 탐색기에서 그 폴더를 열어둔 상태이거나, 터미널의 현재 위치가 그 폴더 안에 있을 때 생김 \
열려 있는 창을 닫고 현재 위치를 바깥으로 옮긴 뒤 다시 시도하면 됨


<br>
<br>


# 07 복사, 이동, 이름 변경

복사는 `cp 원본 복사본`, 이동은 `mv 기존위치 이동할위치`로 맥과 똑같이 쓸 수 있음 폴더를 통째로 복사할 때는 `cp 원본폴더 복사폴더 -Recurse`처럼 `-Recurse`를 붙여야 함

이름을 바꿀 때도 `mv 기존이름 새이름`이 동작하고, `Rename-Item 기존이름 새이름`을 써도 됨


<br>
<br>


# 08 맥 터미널과 비교하기

맥에서 배운 명령어 중 대부분은 이름이 같지만 옵션이 다르거나 아예 없는 것이 몇 개 있음

| 하는 일 | 맥 터미널 | PowerShell |
| --- | --- | --- |
| 현재 위치 확인 | `pwd` | `pwd` |
| 목록 확인 | `ls` | `ls` (또는 `dir`) |
| 숨김 파일 포함 목록 | `ls -la` | `ls -Force` |
| 폴더 이동 | `cd` | `cd` |
| 폴더 생성 | `mkdir` | `mkdir` |
| 빈 파일 생성 | `touch a.txt` | `New-Item a.txt -ItemType File` |
| 파일 삭제 | `rm a.txt` | `rm a.txt` |
| 폴더 삭제 | `rm -rf 폴더` | `Remove-Item -Recurse -Force 폴더` |
| 복사 | `cp` | `cp` (폴더는 `-Recurse`) |
| 이동, 이름 변경 | `mv` | `mv` |
| 화면 정리 | `clear` | `clear` 또는 `cls` |

Git 명령어(`git add`, `git commit` 등)는 맥과 PowerShell에서 완전히 똑같이 동작


<br>
<br>


# 09 알아두면 편한 기능

* `Tab` : 파일이나 폴더 이름을 앞부분만 쓰고 누르면 자동으로 완성해줌
* `↑` `↓` : 이전에 입력한 명령어를 다시 불러옴
* `Ctrl + C` : 실행 중인 명령어를 중단함 (글자를 선택한 상태에서는 복사)
* `cls` : 화면을 깨끗하게 지움

폴더 이름이 길 때는 처음 몇 글자만 치고 `Tab`을 누르는 방식이 오타도 줄이고 훨씬 빠름

# 정리

| 명령어 | 역할 |
| --- | --- |
| `pwd` | 현재 위치 확인 |
| `ls` | 파일과 폴더 목록 확인 |
| `ls -Force` | 숨김 파일까지 확인 |
| `cd 폴더명` | 폴더 이동 |
| `cd ..` | 한 단계 위로 이동 |
| `mkdir 폴더명` | 폴더 생성 |
| `New-Item 파일명 -ItemType File` | 빈 파일 생성 |
| `rm 파일명` | 파일 삭제 |
| `Remove-Item -Recurse -Force 폴더명` | 폴더 삭제 |
| `cp`, `mv` | 복사, 이동 및 이름 변경 |
| `cls` | 화면 정리 |
