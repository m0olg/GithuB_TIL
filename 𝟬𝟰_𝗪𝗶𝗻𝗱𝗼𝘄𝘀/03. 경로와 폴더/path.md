## 경로와 폴더
 
<br>
<br>

# 01 경로란?
 
→ 경로(path)는 **파일이나 폴더가 컴퓨터 어디에 있는지 알려주는 주소**임
 
터미널에서 폴더를 이동하거나 파일을 지우고 옮길 때 그리고 Git 저장소의 위치를 확인할 때 모두 경로를 기준으로 동작함 \
경로를 읽을 줄 알면 "지금 내가 어디에 있는지"를 파악할 수 있어서 실수가 크게 줄어듦
 
 
<br>
<br>
 
# 02 절대 경로와 상대 경로
 
경로를 적는 방법은 두 가지가 있음
 
**절대 경로**는 맨 처음 위치(드라이브)부터 끝까지 전부 적는 방식임 \
지금 어디에 있든 항상 같은 곳을 가리킴
 
```
C:\Users\사용자이름\Desktop\프로젝트
```
 
**상대 경로**는 지금 위치를 기준으로 적는 방식임 \
현재 위치가 `Desktop`일 때 `프로젝트` 폴더로 가고 싶다면 그냥 `프로젝트`라고만 적으면 됨 \
같은 표기라도 어디서 실행하느냐에 따라 가리키는 곳이 달라짐
 
처음에는 절대 경로가 헷갈릴 일이 없고 익숙해지면 상대 경로가 짧아서 편함
 
 
<br>
<br>
 
# 03 자주 쓰는 경로 기호
 
* `.` : 현재 폴더
* `..` : 한 단계 위 폴더(상위 폴더)
* `~` : 사용자의 홈 폴더 (`C:\Users\사용자이름`)
`..`은 여러 번 이어서 쓸 수도 있음 \
`cd ..\..`는 두 단계 위로 올라간다는 뜻임 (Git Bash에서는 `cd ../..`)
 
 
<br>
<br>
 
# 04 윈도우와 맥의 경로 차이
 
| 구분 | 윈도우 | 맥 |
| --- | --- | --- |
| 구분 기호 | `\` (역슬래시) | `/` (슬래시) |
| 시작 | 드라이브 문자 (`C:\`) | 루트 (`/`) |
| 사용자 폴더 | `C:\Users\이름` | `/Users/이름` |
| 바탕화면 | `C:\Users\이름\Desktop` | `/Users/이름/Desktop` |
 
윈도우는 드라이브가 `C:` `D:`처럼 나뉘어 있고 맥은 하나의 루트 아래에 모든 것이 들어 있다는 점이 가장 큰 차이임
 
PowerShell은 역슬래시와 슬래시를 둘 다 알아듣는 편이지만 Git Bash는 슬래시만 안전하게 쓸 수 있음 \
Git Bash에서는 `C:\Users\이름`을 `/c/Users/이름`으로 적음
