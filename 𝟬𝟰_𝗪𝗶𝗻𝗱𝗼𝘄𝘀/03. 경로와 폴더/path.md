## 경로와 폴더
 
<br>
<br>

# 01 경로란?
 
→ <mark>경로(path)는 **파일이나 폴더가 컴퓨터 어디에 있는지 알려주는 주소**</mark>임
 
터미널에서 폴더를 이동하거나 파일을 지우고 옮길 때 그리고 Git 저장소의 위치를 확인할 때 모두 경로를 기준으로 동작함 \
경로를 읽을 줄 알면 "지금 내가 어디에 있는지"를 파악할 수 있어서 실수가 크게 줄어듦
 
 
<br>
<br>
 
# 02 절대 경로와 상대 경로
 
경로를 적는 방법은 두 가지가 있음
 
**절대 경로**는 맨 처음 위치(드라이브)부터 끝까지 전부 적는 방식임 \
지금 어디에 있든 항상 같은 곳을 가리킴
 
```
C:\Users\사용자이름\Desktop\프로젝트
```
 
**상대 경로**는 지금 위치를 기준으로 적는 방식임 \
현재 위치가 `Desktop`일 때 `프로젝트` 폴더로 가고 싶다면 그냥 `프로젝트`라고만 적으면 됨 \
같은 표기라도 어디서 실행하느냐에 따라 가리키는 곳이 달라짐
 
처음에는 절대 경로가 헷갈릴 일이 없고 익숙해지면 상대 경로가 짧아서 편함
 
 
<br>
<br>
 
# 03 자주 쓰는 경로 기호
 
* `.` : 현재 폴더
* `..` : 한 단계 위 폴더(상위 폴더)
* `~` : 사용자의 홈 폴더 (`C:\Users\사용자이름`)
`..`은 여러 번 이어서 쓸 수도 있음 \
`cd ..\..`는 두 단계 위로 올라간다는 뜻임 (Git Bash에서는 `cd ../..`)
 
 
<br>
<br>
 
# 04 윈도우와 맥의 경로 차이
 
| 구분 | 윈도우 | 맥 |
| --- | --- | --- |
| 구분 기호 | `\` (역슬래시) | `/` (슬래시) |
| 시작 | 드라이브 문자 (`C:\`) | 루트 (`/`) |
| 사용자 폴더 | `C:\Users\이름` | `/Users/이름` |
| 바탕화면 | `C:\Users\이름\Desktop` | `/Users/이름/Desktop` |
 
윈도우는 드라이브가 `C:` `D:`처럼 나뉘어 있고 맥은 하나의 루트 아래에 모든 것이 들어 있다는 점이 가장 큰 차이임
 
PowerShell은 역슬래시와 슬래시를 둘 다 알아듣는 편이지만 Git Bash는 슬래시만 안전하게 쓸 수 있음 \
Git Bash에서는 `C:\Users\이름`을 `/c/Users/이름`으로 적음
 
 
<br>
<br>

# 05 바탕화면 경로가 다를 수 있음
 
보통 바탕화면은 `C:\Users\사용자이름\Desktop`에 있지만 OneDrive 백업이 켜져 있으면 `C:\Users\사용자이름\OneDrive\Desktop`처럼 중간에 `OneDrive`가 끼어 있기도 함
 
`cd Desktop`으로 이동했는데 폴더를 못 찾는다는 에러가 나면 이 경우일 수 있음 \
먼저 `pwd`와 `ls`로 지금 위치와 안에 있는 폴더를 확인해보는 것이 가장 빠름
 
 
<br>
<br>
 
# 06 경로 복사하기
 
탐색기에서 경로를 복사하는 방법은 두 가지가 있음
 
* 폴더나 파일을 선택하고 `Ctrl + Shift + C`를 누르면 경로로 복사됨
* 위쪽 주소창을 한 번 클릭하면 경로가 글자로 바뀌는데 이걸 `Ctrl + C`로 복사함
`Ctrl + Shift + C`는 우클릭 메뉴의 `경로로 복사`와 같은 기능이며 복사된 경로에는 양쪽에 큰따옴표가 붙어 있음
 
터미널에는 `cd`를 입력하고 한 칸 띄운 뒤 붙여넣으면 바로 이동할 수 있음 \
다만 Git Bash에서는 역슬래시 때문에 경로가 깨질 수 있으므로 따옴표로 감싸야 함
 
 
<br>
<br>
 
# 07 띄어쓰기와 한글이 들어간 폴더 이름
 
폴더 이름에 띄어쓰기가 있으면 터미널이 이름을 두 개로 나눠서 읽기 때문에 따옴표로 감싸야 함
 
```
cd "My Project"
```
 
한글 이름도 대부분 문제없이 동작하지만 도구에 따라 깨지거나 에러가 나는 경우가 가끔 있음 \
그래서 프로젝트 폴더는 가능하면 영문에 띄어쓰기 없이 짓는 것이 안전함 \
띄어쓰기가 필요하다면 `-`나 `_`로 대신하면 됨
 
 
<br>
<br>
 
# 08 폴더 위치 때문에 생기는 실수
 
경로를 제대로 확인하지 않아서 생기는 실수가 꽤 흔함
 
**레포 안에 레포 만들기** \
이미 어떤 Git 저장소 폴더 안에서 `git clone`을 실행하면 그 안에 또 다른 저장소가 생김 \
폴더가 겹겹이 쌓여서 나중에 정리하기 번거로워짐 \
`git clone`이나 `git init`을 하기 전에는 `pwd`로 지금 위치를 꼭 확인하는 습관이 좋음
 
**지금 있는 폴더는 지울 수 없음** \
터미널의 현재 위치가 그 폴더 안에 있거나 VS Code가 그 폴더를 열고 있으면 삭제할 때 "다른 프로세스가 사용 중"이라는 에러가 남 \
바깥 폴더로 먼저 이동하고 VS Code도 다른 폴더로 열어준 뒤 지우면 됨
 
**엉뚱한 곳에서 명령어 실행하기** \
`rm`처럼 삭제하는 명령어는 특히 위치를 확인하고 입력해야 함 \
`pwd`와 `ls`로 확인하는 것이 습관이 되면 대부분 막을 수 있음
