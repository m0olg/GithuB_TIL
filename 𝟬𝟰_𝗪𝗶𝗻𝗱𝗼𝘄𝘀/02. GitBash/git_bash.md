## Git Bash
 
<br>
<br>

# 01 Git Bash란?
 
→ <mark>Git Bash는 **윈도우에서 맥과 같은 방식의 명령어를 쓸 수 있게 해주는 터미널**임
 
Git을 윈도우에 설치하면 함께 설치되며 맥 터미널에서 쓰던 `ls -la` `rm -rf` `touch` 같은 명령어를 그대로 입력할 수 있음 \
맥에서 정리한 명령어를 윈도우에서도 똑같이 쓰고 싶을 때 편함
 
 
<br>
<br>
 
# 02 설치와 실행
 
Git 공식 사이트(git-scm.com)에서 윈도우용 Git을 내려받아 설치하면 Git Bash도 같이 설치됨 \
설치 중 나오는 옵션은 기본값으로 두고 계속 진행해도 충분함
 
### 설치 확인
 
```bash
git --version
```
 
버전이 출력되면 Git이 정상적으로 설치된 것임
 
### 실행 방법
 
* 시작 메뉴에서 `Git Bash`를 검색해서 실행함
* 탐색기에서 원하는 폴더 안의 빈 곳을 우클릭하고 `Open Git Bash here`를 선택하면 그 폴더에서 바로 열림
> 윈도우 11에서는 `추가 옵션 표시`를 눌러야 보일 수 있음
 
 
<br>
<br>
 
# 03 PowerShell과 무엇이 다른가
 
가장 큰 차이는 **명령어 체계**임 \
PowerShell은 윈도우 방식의 명령어를 쓰고 Git Bash는 맥과 같은 `bash` 방식의 명령어를 씀
 
예를 들어 숨김 파일까지 목록을 볼 때 PowerShell에서는 `ls -Force`를 쓰지만 Git Bash에서는 맥과 똑같이 `ls -la`를 씀 \
폴더를 강제로 지우는 `rm -rf`나 빈 파일을 만드는 `touch`도 Git Bash에서는 그대로 동작함
 
Git 명령어 자체(`git add` `git commit` 등)는 어느 쪽에서 입력해도 결과가 같음
 
 
<br>
<br>
 
# 04 경로 표기
 
Git Bash에서는 윈도우 경로를 **슬래시(`/`)** 로 쓰고 드라이브 문자는 폴더처럼 취급함
 
`C:\Users\사용자이름\Desktop`은 Git Bash에서 `/c/Users/사용자이름/Desktop`으로 표기됨 \
`pwd`를 입력했을 때 이런 형태로 나오면 정상임
 
탐색기에서 복사한 경로를 그대로 붙여넣으면 역슬래시(`\`)가 특수 문자로 처리되어 경로가 깨짐 \
이럴 때는 경로 전체를 따옴표로 감싸거나 역슬래시를 슬래시로 바꿔서 입력해야 함 \
경로에 대한 자세한 내용은 경로와 폴더 문서에서 이어서 다룸
 
 
<br>
<br>
 
# 05 자주 쓰는 명령어
 
기본 명령어는 맥 터미널 문서에서 정리한 것과 같음
 
* `pwd` : 현재 위치 확인
* `ls` / `ls -la` : 목록 확인과 숨김 파일 포함 목록 확인
* `cd` : 폴더 이동
* `mkdir` / `touch` : 폴더 생성과 빈 파일 생성
* `rm` / `rm -r` : 파일 삭제와 폴더 삭제
* `cp` / `mv` : 복사와 이동 및 이름 변경
* `clear` : 화면 정리 (`Ctrl + L`로도 가능함)
`rm`은 맥과 마찬가지로 휴지통을 거치지 않고 바로 삭제됨 \
특히 `rm -rf`는 경로를 한 번 더 확인하고 입력해야 함
 
 
<br>
<br>
 
# 06 복사와 붙여넣기 주의점
 
Git Bash 창에서는 `Ctrl + C`가 복사가 아니라 **실행 중인 명령어를 중단**하는 단축키로 동작함
 
글자를 복사하려면 드래그로 선택하거나 `Ctrl + Insert`를 쓰고 붙여넣기는 마우스 우클릭이나 `Shift + Insert`를 쓰면 됨 \
처음에는 `Ctrl + V`가 안 먹어서 당황하기 쉬움
 
 
<br>
<br>

# 07 VS Code에서 Git Bash 쓰기
 
Git Bash가 설치되어 있으면 VS Code 터미널에서도 선택해서 쓸 수 있음
 
터미널 패널 위쪽의 `+` 버튼 옆 화살표(드롭다운)를 누르면 `Git Bash`가 목록에 나타나고 선택하면 새 터미널이 Git Bash로 열림 \
계속 이 터미널을 기본으로 쓰고 싶다면 같은 메뉴의 `기본 프로필 선택`에서 `Git Bash`를 고르면 됨
 
 
<br>
<br>
 
# 08 PowerShell과 Git Bash 중 무엇을 쓸까
 
둘 다 Git 작업에는 문제가 없고 어느 쪽이 더 좋다기보다 취향과 상황의 문제임
 
* 맥에서 정리한 명령어를 그대로 쓰고 싶다면 Git Bash가 편함
* 설치 없이 윈도우 기본 환경에서 바로 쓰고 싶다면 PowerShell이 편함
한 번 정한 터미널로 계속 쓰는 편이 덜 헷갈림 \
명령어가 안 먹힐 때는 지금 어느 터미널인지부터 확인하는 것이 좋음
 
 
<br>

# 정리
 
| 구분 | PowerShell | Git Bash |
| --- | --- | --- |
| 설치 | 윈도우에 기본 포함 | Git 설치 시 함께 설치 |
| 명령어 방식 | 윈도우 방식 | 맥과 같은 bash 방식 |
| 숨김 파일 목록 | `ls -Force` | `ls -la` |
| 폴더 강제 삭제 | `Remove-Item -Recurse -Force` | `rm -rf` |
| 경로 표기 | `C:\Users\...` | `/c/Users/...` |
| `Ctrl + C` | 중단 (선택 시 복사) | 실행 중단 |
